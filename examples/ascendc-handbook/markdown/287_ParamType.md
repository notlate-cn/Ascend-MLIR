# ParamType

#### 功能说明

定义算子参数类型。

#### 函数原型
    
    
    OpParamDef &ParamType(Option param_type)
    

#### 参数说明

展开

参数 | 输入/输出 | 说明  
---|---|---  
**param_type** | 输入 | 参数类型，Option取值为：OPTIONAL（可选）、REQUIRED（必选）、DYNAMIC（动态输入）。  
  
#### 返回值说明

OpParamDef算子定义，OpParamDef请参考[OpParamDef](atlasascendc_api_07_0957.html)。

#### 约束说明

无
