# Legacy AscGraph Mapping

This document used to describe a prototype frontend-dialect mapping for
AscGraph protobuf input.

That prototype is not part of the active Ascend V2 compiler architecture. New
development should use the Ascend V2 contract:

- `docs/Ascend-MLIR-Detailed-Implementation-V2.zh.md`
- `docs/Ascend-MLIR-Detailed-Implementation-V2-1.zh.md`
- `docs/Ascend-MLIR-Detailed-Implementation-V2-6.zh.md`
- `docs/Ascend-MLIR-Detailed-Implementation-V2-9.zh.md`

Historical details remain available in git history. Do not add new code,
tests, or documentation that depend on the prototype frontend-dialect mapping.
